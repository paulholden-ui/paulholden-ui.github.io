Privacy Policy — Holden Nest

Last updated: September 28, 2026

Holden Nest is a personal smart-home integration built for the account holder's own household. It connects to the holder's Google Home devices (thermostats, cameras, lights) through Google's official APIs in order to display device status and carry out commands the holder explicitly requests.

Data we access

  • Device names, types, traits, and current states (e.g. temperature, on/off).
  • Camera and doorbell event history available through the holder's Google Home Premium subscription.

How data is used

Data is used solely to operate the holder's own smart home: showing device status and executing the holder's requested actions. Data is not sold, shared with third parties, or used for advertising.

Data storage

OAuth tokens are stored securely on the holder's own infrastructure and are never exposed publicly. No home data is stored on this website.

Contact

Questions about this policy can be directed to the account holder via the GitHub profile associated with this site.
